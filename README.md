# Clothify Next.js

A modern clothing ecommerce + admin panel UI built with **Next.js (App Router)**.

## Features

- Home page with hero, categories, trending products
- Product listing with filters, search, and sorting
- Cart, checkout, and orders (stored in localStorage)
- Simple auth: login/register/profile (front-end only)
- Admin dashboard with:
  - Overview metrics
  - Product catalog management (add/delete)
  - Orders status update
  - Single user view (from demo auth)
- Dark modern UI with light animations

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000


Images: default products use remote Pexels URLs; admin can add custom image URLs per product.
